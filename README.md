# Landing de Inmobiliaria Boutique

Landing page demo para una inmobiliaria boutique.

## Qué resuelve

Presenta el catálogo de propiedades y captura contactos de interesados en comprar, vender o arrendar.

## Stack técnico

- React + TypeScript + Vite
- Tailwind CSS
- Supabase (contactos/leads)

## Estado

Demo de portafolio.
